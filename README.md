# FORM / 01 — Barbershop Website Concept

A responsive, fictional barbershop demonstration website for a web-design portfolio.

## Publish on GitHub Pages

1. Create a **public** repository named `form-barbers-demo`.
2. Upload `index.html`, `styles.css`, and `script.js` to the **root** of the repository (not a ZIP or nested folder).
3. Under **Settings → Pages**, select **Deploy from a branch**, **main**, **/(root)** and save.
4. Once deployed, the URL should be `https://samcodes432.github.io/form-barbers-demo/` if published under the `samcodes432` account.

## Portfolio link

Point the existing Form Barbers project card to the deployed GitHub Pages URL. Make the `<article>` clickable by wrapping it in an `<a href="...">` tag, or add a link inside the card.

## Notes

- Fictional brand, services, and pricing. No actual bookings or email collection.
- Abstract CSS artwork is used instead of unlicensed photographs.
- Fonts load from Google Fonts when online; local fallbacks are provided.
